1. HR Analytics Dashboard – Power BI

Objective: Analyze employee information, workforce distribution, and employee attrition to identify HR trends.

Key KPIs:

-Total Employees

-Attrition Count

-Attrition Rate

-Average Salary

-Average Age

-Average Years of Experience

Dashboard Insights:

-Attrition analysis by education field.

-Employee distribution by gender.

-Attrition analysis by age group.

-Salary slab and attrition analysis.

-Job role analysis.

Tools: Power BI, Data Visualization, Data Analysis

Project folder: HR-Analytics
